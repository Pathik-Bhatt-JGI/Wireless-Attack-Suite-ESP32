========================================
STEP 4: CONNECT ESP32
========================================

1. Connect your ESP32 DevKit V1 to USB
2. Check which COM port it's using:
   - Open Device Manager
   - Look under "Ports (COM & LPT)"
   - Note the COM port (example: COM3, COM5, etc.)

========================================
STEP 5: FLASH TO ESP32
========================================

Replace COMX with your actual COM port:

idf.py -p COMX flash

Example:
idf.py -p COM3 flash

This will:
- Erase the flash
- Upload bootloader
- Upload partition table  
- Upload firmware

========================================
STEP 6: MONITOR OUTPUT (OPTIONAL)
========================================

To see real-time logs from ESP32:

idf.py -p COMX monitor

To exit monitor: Press Ctrl+]

Or flash AND monitor in one command:

idf.py -p COMX flash monitor

========================================
TROUBLESHOOTING
========================================

❌ "idf.py not recognized"
   → Run the ESP-IDF export script first (Step 1)

❌ "Cannot open port COMX"
   → Check Device Manager for correct COM port
   → Close any serial monitor programs
   → Try unplugging and replugging ESP32

❌ "Failed to connect to ESP32"
   → Hold BOOT button on ESP32
   → Press and release EN button
   → Release BOOT button
   → Try flash command again

❌ Build fails with errors
   → Run: idf.py fullclean
   → Then: idf.py build
