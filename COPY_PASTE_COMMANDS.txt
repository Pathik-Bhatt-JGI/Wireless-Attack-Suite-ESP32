   PATHIKS ESP32 - COPY & PASTE THESE COMMANDS
════════════════════════════════════════════════════════

📋 STEP 1: OPEN ESP-IDF TERMINAL
────────────────────────────────────────────────────────
Look for this shortcut on your Desktop or Start Menu:
"ESP-IDF 5.5 CMD"

Or double-click this file:
C:\Espressif\frameworks\esp-idf-v5.5.5\export.bat

────────────────────────────────────────────────────────

📋 STEP 2: COPY AND PASTE THIS
────────────────────────────────────────────────────────
cd C:\Users\pathi\Downloads\final_build_with_button_attacks\final_build_with_button_attacks

────────────────────────────────────────────────────────

📋 STEP 3: BUILD THE FIRMWARE
────────────────────────────────────────────────────────
idf.py build

WAIT 2-5 MINUTES - Let it compile everything!

────────────────────────────────────────────────────────

📋 STEP 4: CHECK YOUR COM PORT
────────────────────────────────────────────────────────
1. Press Windows Key + X
2. Click "Device Manager"
3. Expand "Ports (COM & LPT)"
4. Plug in your ESP32 via USB
5. Look for "USB-SERIAL CH340" or "CP2102" or similar
6. Note the COM port number (COM3, COM4, COM5, etc.)

────────────────────────────────────────────────────────

📋 STEP 5: FLASH TO ESP32
────────────────────────────────────────────────────────
Replace COMX with your actual port number!

If your port is COM3:
idf.py -p COM3 flash

If your port is COM4:
idf.py -p COM4 flash

If your port is COM5:
idf.py -p COM5 flash

────────────────────────────────────────────────────────

📋 STEP 6: MONITOR OUTPUT (OPTIONAL)
────────────────────────────────────────────────────────
To see live serial output:

idf.py -p COM3 monitor

(Replace COM3 with your port)

To exit monitor, press: Ctrl + ]

────────────────────────────────────────────────────────

🎯 ALL COMMANDS IN ONE GO (For COM3):
────────────────────────────────────────────────────────
cd C:\Users\pathi\Downloads\final_build_with_button_attacks\final_build_with_button_attacks
idf.py build
idf.py -p COM3 flash
idf.py -p COM3 monitor

────────────────────────────────────────────────────────

⚠️ IF BUILD FAILS
────────────────────────────────────────────────────────
Run this to clean everything:

idf.py fullclean

Then build again:

idf.py build

────────────────────────────────────────────────────────

⚠️ IF FLASH FAILS
────────────────────────────────────────────────────────
Put ESP32 in manual flash mode:

1. Hold down the BOOT button on ESP32
2. While holding BOOT, press and release EN button
3. Release BOOT button
4. Now run the flash command again

────────────────────────────────────────────────────────

✅ AFTER SUCCESSFUL FLASH
────────────────────────────────────────────────────────
Your ESP32 will reboot and show:

📺 OLED Display:
   - Boot logo: 🖕 (middle finger)
   - "PATHIKS ONLINE"

📶 WiFi Network:
   - SSID: pathiks
   - Password: 12345678

🌐 Web Interface:
   1. Connect to WiFi "pathiks"
   2. Open browser: http://192.168.4.1

📱 Bluetooth:
   - Device name: PATHIKS-XXXX (random number)

────────────────────────────────────────────────────────

🎉 DONE! Your PATHIKS device is ready to use!
