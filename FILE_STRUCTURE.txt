BUILD OUTPUT LOCATIONS:
═══════════════════════════════════════════════════════════════════════

After running "idf.py build", you'll find:

build/pathiks-esp32.bin         ← Main firmware binary
build/bootloader/bootloader.bin ← Bootloader binary
build/partition_table/          ← Partition table
build/spiffs/                   ← SPIFFS filesystem
build/*.map                     ← Memory map files (for debugging)


IMPORTANT DIRECTORIES:
═══════════════════════════════════════════════════════════════════════

DO NOT DELETE:
  components/     ← External libraries (needed for build)
  main/           ← Your application code
  data/           ← Web interface files
  sdkconfig       ← Configuration (will regenerate but takes time)

SAFE TO DELETE (will regenerate):
  build/          ← Build output (deleted by "idf.py fullclean")


CONFIGURATION FILES:
═══════════════════════════════════════════════════════════════════════

sdkconfig               ← Main ESP-IDF configuration
                          • WiFi settings
                          • Bluetooth settings
                          • Memory allocation
                          • Debug levels
                          
partitions.csv          ← Flash memory layout
                          • Boot partition
                          • App partition
                          • SPIFFS storage
                          • NVS storage

CMakeLists.txt (root)   ← Project-level build config
main/CMakeLists.txt     ← Component-level build config
