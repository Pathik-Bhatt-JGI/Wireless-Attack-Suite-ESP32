═══════════════════════════════════════════════════════════════════════
                      TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: "idf.py is not recognized"
Fix:     This is normal! The batch script will fix it automatically.
         It calls C:\Espressif\frameworks\esp-idf-v5.5.5\export.bat

Problem: "Failed to connect to ESP32"
Fix:     • Check USB cable (must be data cable)
         • Hold BOOT button on ESP32
         • Try different USB port
         • Check COM port in Device Manager

Problem: Build errors
Fix:     Run: idf.py fullclean
         Then run FLASH_PATHIKS.bat again

Problem: Wrong COM port
Fix:     1. Open Device Manager
         2. Find your ESP32 under "Ports (COM & LPT)"
         3. Edit FLASH_PATHIKS.bat
         4. Change "COM17" to your port number
