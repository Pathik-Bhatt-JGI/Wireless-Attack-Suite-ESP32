📋 WHAT YOU NEED:

  ✅ ESP32 DevKit V1 board
  ✅ USB cable (micro USB with data, not charge-only)
  ✅ Windows PC
  ✅ ESP-IDF installed

═══════════════════════════════════════════════════════════════════

🚀 IF ESP-IDF ALREADY INSTALLED:

  1. Open "ESP-IDF PowerShell" from Start Menu
  
  2. Navigate to project:
     cd C:\Users\pathi\Downloads\final_build_with_button_attacks\final_build_with_button_attacks
  
  3. Build:
     idf.py build
     (Wait 5-10 minutes first time)
  
  4. Connect ESP32 via USB
  
  5. Check COM port in Device Manager
     (Usually COM3, COM4, or COM5)
  
  6. Flash:
     idf.py -p COM3 flash
     (Replace COM3 with your port)
  
  7. Done! ESP32 reboots with middle finger logo! 🖕

═══════════════════════════════════════════════════════════════════

📥 IF ESP-IDF NOT INSTALLED:

  Step 1: Download ESP-IDF Installer
  
    → Go to: https://dl.espressif.com/dl/esp-idf/
    → Download: "ESP-IDF Tools Installer (Windows)"
    → File: esp-idf-tools-setup-x.x.x.exe
  
  Step 2: Install
  
    → Run the .exe file
    → Choose "Express Installation"
    → Select ESP-IDF v5.0 or newer
    → Click Install
    → Wait 20-30 minutes (downloads ~2GB)
    → Reboot PC when done
  
  Step 3: Flash (follow steps above)

═══════════════════════════════════════════════════════════════════

🔧 DRIVER ISSUES?

  If ESP32 not detected:
  
  → Download CH340 driver:
    http://www.wch.cn/downloads/CH341SER_ZIP.html
  
  → Or CP210x driver:
    https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
  
  → Install driver
  → Restart PC
  → Reconnect ESP32

🐛 TROUBLESHOOTING:

  Problem: "idf.py not found"
  Fix: Use ESP-IDF PowerShell, not regular cmd

  Problem: "Failed to connect"
  Fix: Hold BOOT button on ESP32, then run flash command

  Problem: "Port busy"
  Fix: Close Arduino IDE, serial monitors, other terminals

  Problem: "Permission denied"
  Fix: Run as Administrator

  Problem: Build errors
  Fix: idf.py fullclean, then idf.py build

📱 FIND COM PORT:

  Method 1 - Device Manager:
    → Press Windows + X
    → Click "Device Manager"
    → Expand "Ports (COM & LPT)"
    → Look for "USB-SERIAL" or "CP210x"
    → Note COM number (e.g., COM3)

  Method 2 - Try each:
    idf.py -p COM3 flash
    idf.py -p COM4 flash
    idf.py -p COM5 flash
    (One will work)
