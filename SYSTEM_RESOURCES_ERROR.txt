╔════════════════════════════════════════════════════════════════════╗
║              SYSTEM RESOURCES ERROR - HOW TO FIX                   ║
╚════════════════════════════════════════════════════════════════════╝

ERROR SEEN:
════════════════════════════════════════════════════════════════════
ninja: fatal: CreateProcess: Insufficient system resources exist to 
complete the requested service.

WHAT THIS MEANS:
════════════════════════════════════════════════════════════════════
Your computer is running out of:
- RAM (memory)
- Process handles
- CPU resources

The ESP-IDF build process is VERY resource-intensive. It tries to
compile many files in parallel, which can overwhelm the system.

SOLUTION 1: FREE UP MEMORY (RECOMMENDED) ⭐
════════════════════════════════════════════════════════════════════
1. Close ALL other programs:
   - Web browsers (Chrome, Firefox, Edge)
   - Other IDEs or text editors
   - Discord, Slack, Teams
   - Games or heavy applications

2. Check Task Manager (Ctrl+Shift+Esc):
   - Look at Memory usage
   - Close any high-memory programs
   - Aim to have at least 2GB free

3. Restart your computer (clears everything)

4. After restart, ONLY open ESP-IDF CMD

5. Run: BUILD_SLOW_LOW_MEMORY.bat

SOLUTION 2: BUILD WITH LESS PARALLELISM
════════════════════════════════════════════════════════════════════
Use the low-memory build script which limits to 2 CPU cores:

   BUILD_SLOW_LOW_MEMORY.bat

This is SLOWER (5-10 minutes) but uses less memory.

SOLUTION 3: INCREASE VIRTUAL MEMORY (Windows)
════════════════════════════════════════════════════════════════════
1. Right-click "This PC" → Properties
2. Click "Advanced system settings"
3. Under Performance, click "Settings"
4. Go to "Advanced" tab
5. Under Virtual Memory, click "Change"
6. Uncheck "Automatically manage"
7. Set Custom size:
   - Initial: 4096 MB
   - Maximum: 8192 MB
8. Click "Set" then "OK"
9. Restart computer

SOLUTION 4: CHECK YOUR SYSTEM
════════════════════════════════════════════════════════════════════
Minimum Requirements:
- RAM: 4GB (8GB recommended)
- Free disk space: 10GB
- CPU: Dual-core minimum

Check if you meet these requirements.

WHAT TO DO NOW:
════════════════════════════════════════════════════════════════════

QUICKEST FIX:
1. Close ALL programs
2. Restart computer
3. Open only ESP-IDF CMD
4. Run: BUILD_SLOW_LOW_MEMORY.bat

OR MANUAL BUILD:
1. Close ALL programs
2. Restart computer
3. Open ESP-IDF CMD
4. Navigate to project
5. Type: set NINJA_ARGS=-j 2
6. Type: del sdkconfig
7. Type: idf.py build
8. Wait 5-10 minutes

WHY THIS HAPPENS:
════════════════════════════════════════════════════════════════════
ESP-IDF builds hundreds of C/C++ files. By default, it tries to
compile 8-16 files at once (parallel build). Each compiler process
uses ~200-300MB of RAM.

Total memory usage during build: 2-4GB

If your system doesn't have enough free RAM, Windows refuses to
create new processes, causing the error.

AFTER SUCCESSFUL BUILD:
════════════════════════════════════════════════════════════════════
Once built successfully, you won't need to rebuild unless you
change the code. Flashing is quick and doesn't use much memory.

TROUBLESHOOTING CHECKLIST:
════════════════════════════════════════════════════════════════════
□ Closed all other programs
□ Restarted computer
□ Using BUILD_SLOW_LOW_MEMORY.bat
□ Increased virtual memory (if needed)
□ Waiting patiently (build takes 5-10 min with -j 2)

STILL FAILING?
════════════════════════════════════════════════════════════════════
Check Task Manager during build:
- If Memory reaches 90-100%, you need more RAM or to close programs
- If CPU is at 100%, that's normal (it's compiling)
- If Disk is at 100%, you may have disk issues

You may need to:
- Upgrade RAM (if < 4GB)
- Build on a different computer
- Use a Linux VM with more allocated memory
