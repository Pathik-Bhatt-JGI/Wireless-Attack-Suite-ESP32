   OPEN START MENU → SEARCH "ESP-IDF 5.5 CMD"

   This opens a special command prompt with ESP-IDF pre-configured.

   - "ESP-IDF 5.5 CMD" or

   Click it to open.

❌ "Can't find ESP-IDF 5.5 CMD in Start Menu"
   → Read: START_HERE.txt (Alternative Method section)

   → Open Notepad
   → Open: SIMPLE_BUILD_FLASH.bat

   → Save and run again

   → Read: PYTHON_ENV_FIX_GUIDE.md
